# YOLO 标注工具

一个简单易用的 YOLO 格式目标检测数据标注工具。

## 功能特点

- 图片浏览和导航
- 框选目标进行标注
- 支持类别管理
- YOLO 格式标注文件导出
- 支持键盘快捷键操作
- 已有标注的加载和编辑

## 安装要求

- Python 3.6+
- tkinter (通常随 Python 一起安装)
- Pillow (PIL)

```bash
pip install pillow
```

## 使用方法

1. 运行程序：
```bash
python main.py
```

2. 基本操作：
   - 打开图片：Ctrl+O 或点击"打开图片"按钮
   - 保存标注：Ctrl+S 或点击"保存标签"按钮
   - 切换图片：左右方向键或使用导航按钮
   - 标注操作：鼠标拖拽进行框选

3. 类别管理：
   - 点击"管理类别"进行类别添加和删除
   - 支持类别配置的导入导出

## 快捷键

- `Ctrl+O`: 打开图片
- `Ctrl+S`: 保存标签
- `←`: 上一张图片
- `→`: 下一张图片

## 保存格式

标注文件将以 .txt 格式保存，与图片同名，每行格式为：
```
<class_id> <x_center> <y_center> <width> <height>
```
其中所有值都已归一化到 [0,1] 范围。
